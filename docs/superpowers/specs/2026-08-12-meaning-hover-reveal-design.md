# 單字中文翻譯 hover 揭示設計

## 目標

移除單字卡上的「顯示答案／隱藏答案」按鈕，改成只有滑鼠移入單字中文翻譯區時才暫時揭示翻譯；滑鼠離開後恢復遮罩。

## 範圍與行為

- `blurTranslations` 關閉時，單字中文翻譯維持原本直接顯示。
- `blurTranslations` 開啟時，單字中文翻譯預設模糊。
- 滑鼠移入單字中文翻譯區時清除模糊；滑鼠移出後恢復模糊。
- 鍵盤將焦點移到同一個翻譯區時也清除模糊，離開焦點後恢復，保留基本可及性。
- 例句中文翻譯不受新的 hover 區域影響，仍使用原本的遮罩狀態。
- 不修改單字資料、學習紀錄、複習流程或其他顯示設定。

## 實作方向

在 `WordCard` 將單字翻譯包進可聚焦的揭示區域，移除單字翻譯專用的 React 揭示狀態與按鈕。CSS 以 `:hover` 與 `:focus-within` 覆寫單字翻譯的模糊效果；例句翻譯改用獨立的遮罩 class，避免共用揭示狀態。

## 驗證

- 新增一個可重複執行的 UI 結構檢查，確認按鈕已移除、hover/focus 規則存在、例句翻譯仍使用獨立遮罩 class。
- 執行 `npm test`、`npm run check` 與 `npm run check:types`。
- 以 390px 寬度檢查翻譯區沒有造成水平捲動。

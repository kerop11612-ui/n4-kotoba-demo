# 單字中文翻譯 hover 揭示設計

## 目標

移除單字卡上的「顯示答案／隱藏答案」按鈕，改成只有滑鼠移入單字或例句中文翻譯區時才暫時揭示各自翻譯；滑鼠離開後恢復遮罩。

## 範圍與行為

- `blurTranslations` 關閉時，單字中文翻譯維持原本直接顯示。
- `blurTranslations` 開啟時，單字中文翻譯預設模糊。
- 滑鼠移入單字中文翻譯區時只清除單字翻譯的模糊；滑鼠移出後恢復模糊。
- 滑鼠移入例句中文翻譯區時只清除例句翻譯的模糊；滑鼠移出後恢復模糊。
- 鍵盤將焦點移到同一個翻譯區時也清除模糊，離開焦點後恢復，保留基本可及性。
- 單字與例句翻譯的揭示區域彼此獨立，不會互相連動。
- 不修改單字資料、學習紀錄、複習流程或其他顯示設定。

## 實作方向

在 `WordCard` 將單字與例句翻譯各自包進可聚焦的揭示區域，移除翻譯專用的 React 揭示狀態與按鈕。CSS 以 `:hover` 與 `:focus-within` 覆寫揭示區域內翻譯的模糊效果；兩個區域共用樣式但不共用 hover 狀態。

## 驗證

- 新增一個可重複執行的 UI 結構檢查，確認按鈕已移除、單字與例句各有揭示區域、hover/focus 規則存在且沒有全域遮罩 hover 規則。
- 執行 `npm test`、`npm run check` 與 `npm run check:types`。
- 以 390px 寬度檢查翻譯區沒有造成水平捲動。
